# AISR_LAB
# 🤖 Algorithms for Intelligent Systems and Robotics Lab

This repository contains implementations of experiments performed as part of the **Algorithms for Intelligent Systems and Robotics Lab (CSAI4113P)**.

The experiments cover fundamental concepts of **Artificial Intelligence, Machine Learning, Control Systems, Robotics, Reinforcement Learning, Kalman Filtering, and Robot Operating System (ROS)**.

## 🧪 List of Experiments

### Experiment 1 – Time & Frequency Domain and Pendulum Simulation
- Time-domain representation of signals
- Frequency-domain representation using FFT
- Pendulum simulation using Python
- Visualization using Matplotlib

### Experiment 2 – 8 Queens Problem
Implementation of the **8 Queens Problem** using Python and backtracking.

### Experiment 3 – Search Algorithms
Implementation of:
- Breadth First Search (BFS)
- Depth First Search (DFS)

### Experiment 4 – Hill Climbing
Implementation of the **Hill Climbing Algorithm** for optimization using Python.

### Experiment 5 – Reinforcement Learning
Implementation of a basic **Reinforcement Learning / Q-Learning** algorithm.

### Experiment 6 – Simple Neural Network
Implementation of a simple neural network using an **MLP Classifier**.

### Experiment 7 – Learning Strategies for MLP Classifier
Comparison of different learning strategies for an MLP classifier, including:
- SGD
- Adam
- LBFGS

### Experiment 8 – Kalman Filtering
Implementation of a **Kalman Filter** for estimating values from noisy measurements.
